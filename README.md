# AWS Community — GSMCOE (Pune)

> **Learn. Build. Deploy. Grow.**

A professional, minimal, scalable static website and Progressive Web App (PWA) built for the **AWS Student/Builder Community at Genba Sopanrao Moze College of Engineering (GSMCOE), Pune**.

---

## 🎨 Design Direction

- **Swiss Editorial Aesthetic**: Pure black (`#000000`) and pure white (`#ffffff`) palette, sharp 1px grid borders, generous whitespace, and asymmetric editorial layouts.
- **Times New Roman Focus**: Utilizes **italic Times New Roman** for primary display headings, pull quotes, section tags (`01 / OVERVIEW`), and numerals.
- **Brand Consistency**: Incorporates the official AWS Student Community badge logo.
- **Full-Spreaded Header**: Edge-to-edge layout with a flush right CTA button.

---

## 🛠️ Technology & Architecture

- **Vanilla Stack**: Pure HTML5, CSS3, and JavaScript (ES6+). Zero frameworks, React, Next.js, or complex build steps required.
- **Progressive Web App (PWA)**: Includes `manifest.json`, `sw.js` for offline static asset caching, mobile install prompts, and viewport meta tags.
- **Netlify Deployable**: Ready for instant static hosting via Netlify (`netlify.toml` included).

---

## 📁 Repository Structure

```
.
├── index.html            # Main semantic HTML5 webpage (11 structured sections)
├── style.css             # Swiss editorial stylesheet & responsive design system
├── script.js             # Dynamic events renderer, details modal, mobile drawer & PWA
├── manifest.json         # Web App Manifest for PWA installation
├── sw.js                 # Service Worker for offline asset caching
├── netlify.toml          # Netlify static deployment configuration
├── LICENSE               # MIT License
├── README.md             # Project documentation
└── assets/
    ├── aws_gsmcoe_logo.jpeg # Official community badge image
    ├── logo.svg           # High-resolution vector logo
    └── favicon.svg        # B&W badge favicon
```
